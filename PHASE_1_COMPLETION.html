Phase 1 Deliverables

1. Shared Responsive CSS Foundation

File: /src/main/resources/static/css/responsive.css (984 lines)

Core Features:
  • Global reset with box-sizing: border-box
  • CSS custom properties (design tokens, spacing, z-index, transitions)
  • Responsive typography using clamp() for fluid scaling
  • Desktop sidebar (preserved, 260px, left-fixed)
  • Mobile header (sticky, 64px, visible ≤768px)
  • Mobile drawer navigation (300px, slides from left)
  • Hamburger menu (44×44px touch target, animated to X)
  • Drawer overlay (semi-transparent, clickable to close)
  • Body scroll lock when drawer open
  • Touch-friendly inputs and buttons (44px min height)
  • Print styles

Breakpoints

Size Range Behavior
Desktop >768px Sidebar visible, main content margin-left: 260px
Tablet/Mobile ≤768px Sidebar hidden, mobile header shown
Mobile ≤480px Reduced padding, no rotations, simplified decorations
Small Mobile ≤360px Tighter spacing, adjusted typography, 56px header

Accessibility

  • :focus-visible outlines (2px solid muted-blue)
  • prefers-reduced-motion support
  • ARIA labels on interactive elements
  • Keyboard navigation (Escape, Tab, focus trap)
